# 資産管理シートの週次更新（Google Apps Script）

スプレッドシート「お金関連」のシート7（口座 × 日付の残高マトリクス）に、
毎週自動で新しい日付列を追加するスクリプト。

## 何をするか

1. 最新の記録列の右に1列追加する
2. 前回列を数式・書式ごとコピーする
3. 年行・日付行を実行日で上書きする

前回列をコピーするので、小計行や合計行の数式は相対参照が調整されて新しい列を集計する。
各口座のセルには前回の残高が入った状態になるため、**変動した口座だけ上書きすればよい**。

これは既存シートの実害も潰す。現状は毎回すべての口座を埋めているわけではなく、
埋めなかった口座は空欄のまま残る。前回値が引き継がれないため、
その列で全カードが空欄だと小計が 0 になっていた（実際に複数の列で発生している）。

## 導入手順

1. スプレッドシートを開き、`拡張機能` → `Apps Script`
2. 生成されたエディタに `asset-sheet-weekly.gs` の中身を貼り付ける
3. 上部の関数選択で `dryRun` を選んで実行

   初回は権限の承認を求められる。承認後、実行ログに検出結果が出る。

   ```
   {
     "年行": 3,
     "日付行": 4,
     "最初のデータ列": "F",
     "最後のデータ列": "BQ",
     "最後の日付": "7/18",
     "次に追加される列": "BR"
   }
   ```

   **「最後の日付」がシート上の最新列と一致しているか必ず確認する。**
   ズレていたらレイアウト検出が外しているので、この時点で止めること。

4. `addWeeklyColumn` を手動で1回実行し、列が意図どおり増えるか確認する
   （問題があれば `Ctrl+Z` ではなくシートの版履歴から戻す）
5. `installWeeklyTrigger` を1回だけ実行してトリガーを登録する

## 設定

`CONFIG` を編集する。

| キー | 既定値 | 内容 |
|---|---|---|
| `spreadsheetId` | 「お金関連」のID | 対象スプレッドシート |
| `sheetName` | `シート7` | 対象シート |
| `dateFormat` | `M/d` | 日付行の書式 |
| `yearPolicy` | `onChange` | 年行に年を入れる方針。`onChange` は年が変わったときだけ |
| `notifyEmail` | `''` | 列追加後の通知先。空なら送らない |

実行曜日・時刻は `installWeeklyTrigger` 内の `onWeekDay` / `atHour` を変更して再実行する。

## 注意

- 行や列の位置はハードコードしていない。日付行は「`m/d` 形式のセルが5個以上並ぶ行」、
  年行はその上の「4桁の年が2個以上並ぶ行」として検出する。
  シートの見出し構造を変えると検出条件を見直す必要がある。
- **小計行・合計行が数式ではなく直接入力された値の場合**、
  コピーで前回の数値がそのまま残り、実態とズレる。
  導入前にこれらの行が数式かどうか確認すること。
- `insertColumnAfter` はシート全体に列を挿入する。
  同じ行範囲に別の表が横に並んでいる場合は影響を受ける。
