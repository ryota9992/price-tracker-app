# Yahoo!フリマ 自動再出品

出品した商品が売れたら、**同じ内容でもう一度出品する**ツールです。

ファイルをダブルクリックすると、ブラウザに操作画面が開きます。**あとは画面のボタンを押すだけ**で、コマンドを打つ必要はありません。

---

## ⚠️ はじめに読んでください

- **Yahoo!フリマには「自動で出品する」ための公式のしくみがありません。** そのためこのツールは、あなたのブラウザを自動で動かして出品します。人間の代わりに操作しているイメージです。
- **自動化はYahoo!フリマの利用規約に触れる可能性があり、最悪の場合アカウントが止まるリスクがあります。** 使うかどうかはご自身の判断でお願いします。危険を減らすため、確認の間隔をあける・1日の出品数に上限をつける・深夜は動かさない、といった安全策を最初から入れてあります。
- **パソコンが動いている間だけ動きます。** ノートパソコンを閉じると止まります。
- **最初は必ず「お試し」モードで動かしてください。** 実際には出品せず、入力するところまでで止まります。

---

## 使い方

### 準備するもの

**Node.js** というプログラムが必要です。入っていない場合は起動時に案内が出るので、そのとき https://nodejs.org から「**LTS**」と書かれたほうを入れてください。

### 起動する

フォルダの中にある起動ファイルを**ダブルクリック**するだけです。

| パソコン | ダブルクリックするファイル |
|---|---|
| Mac | `はじめる.command` |
| Windows | `はじめる.bat` |

黒い画面が出たあと、ブラウザに操作画面が開きます。

> **初回だけ数分かかります。** 必要な部品を自動でダウンロードしています。黒い画面に文字が流れますが、そのまま待ってください。
>
> **黒い画面は閉じないでください。** 閉じると止まります。終わるときは黒い画面で `control + C`（Windowsは `Ctrl + C`）を押します。

> **Macで「開発元が未確認のため開けません」と出たら:** ファイルを右クリック →「開く」→ もう一度「開く」を選んでください。初回だけ必要です。

### あとは画面のとおりに

操作画面に 1〜5 の手順が並んでいます。上から順にボタンを押していってください。

| | やること | 説明 |
|---|---|---|
| 1 | **ログイン** | ボタンを押すとブラウザが開くので、いつもどおりログイン。終わったら「ログインできた」を押す |
| 2 | **画面のつくりを調べる** | 自動で調べます。ブラウザが勝手に開閉しますが触らず待つ |
| 3 | **見張る商品を登録** | 「まとめて登録」を押すだけ。写真や説明文を保存します |
| 4 | **動き方を選ぶ** | 最初は「お試し」のまま |
| 5 | **見張りを始める** | これで動き出します |

パスワードがこのツールに渡ることはありません。ログインはあなた自身がブラウザで行います。

---

## ⚠️ 2の「調べる」のあとに、ひとつだけ作業が必要です

Yahoo!フリマの画面のつくりは公開されていないため、**現状の設定は推測で書かれています。そのままでは動かない可能性が高いです。**

手順2を実行すると `data/inspect/` というフォルダに調査結果が保存されます。この中の **`mylistings-0.hints.json`** などのファイルの中身を見せてもらえれば、こちらで設定（`selectors.json`）を書いて動くようにできます。

> `data/auth.json` はログイン情報そのものです。**絶対に他の人に見せないでください。**

---

## 動き方（3つのモード）

画面の「4」で選べます。**上から順に試すのがおすすめ**です。

| モード | 何が起きるか |
|---|---|
| **お試し** | 売れたのを見つけて、出品画面に入力するところまでやって止まる。**実際には出品されない** |
| **半自動** | 売れたら画面にボタンが出る。押すと出品される |
| **完全自動** | 売れたら確認なしでそのまま出品される |

「お試し」で入力内容が正しいことを確認 → 「半自動」で数回ためす → 問題なければ「完全自動」、という順番が安全です。切り替えはボタン1つで、いつでも戻せます。

---

## ぜんたいの流れ

```
出品中の商品を見張る（初期設定では15分おき）
   ↓ 「売却済み」を見つける
保存しておいた写真・説明文・価格を読み出す
   ↓
  半自動 → 画面にボタンが出る → 押すと出品
  完全自動 → そのまま出品
   ↓
出品できたら、新しい商品を自動で見張り対象に引き継ぐ
   ↓
（また売れたら最初に戻る）
```

一度登録すれば、売れるたびにずっと回り続けます。

## 在庫の管理（使いたい人だけ）

**初期状態では在庫は「無制限」**です。売れるたびに何度でも再出品します。

在庫が限られている商品は、**用意できない注文を受けてしまう**ので在庫数を設定してください。商品の右にある「在庫」ボタンから設定できます。

`3` を設定した場合:

| 出来事 | 在庫 | 再出品 |
|---|---|---|
| 1個目が売れた | 2 | する |
| 2個目が売れた | 1 | する |
| 3個目が売れた | 0 | **しない**（「在庫切れ」になって通知） |

補充したら「在庫」ボタンで数を入れ直せば再開します。

## 安全のしくみ

| しくみ | 内容 |
|---|---|
| **緊急停止** | 画面の一番下の赤いボタン。すべて止まります |
| **お試しモード** | 出品の直前で止めて、内容を確認できる |
| **1日の上限** | 1日20件を超えたら止まる |
| **深夜は動かない** | 朝8時〜夜23時のあいだだけ動く |
| **確認の間隔** | 10分より短くはできません。毎回ランダムにずらしてアクセスします |
| **失敗したら止まる** | 5回続けて失敗すると自動で停止します |

## 通知

`config.json` の `notify.webhookUrl` に Slack か Discord の通知用URLを入れると、「売れました」「再出品しました」「失敗しました」がスマホに飛びます。Macならデスクトップ通知も出ます。

---

## うまくいかないとき

**黒い画面やブラウザに出ているメッセージを、そのままコピーして相談してください。** どこで何が出たかがわかれば直せます。

| 症状 | 対処 |
|---|---|
| ダブルクリックしても何も起きない | Node.js が入っていない可能性大。https://nodejs.org のLTSを入れる |
| Macで「開けません」と出る | ファイルを右クリック →「開く」→ もう一度「開く」 |
| 「一覧ページを開けませんでした」 | 手順2をやって、結果を相談してください（設定の調整が必要です） |
| 商品名や価格が空になる | 同上 |
| 売れたのに気づかない | 同上 |
| ログインが切れた | 手順1をもう一度やる。数週間ごとに必要です |

動作の記録は画面の「動作の記録」欄と、`data/bot.log` に残ります。

# ここから下は、詳しい人向け

## コマンドで操作する

画面を使わず、ターミナルからも操作できます。

| コマンド | 内容 |
|---|---|
| `npm run app` | 操作画面を起動（ダブルクリックと同じ） |
| `npm run login` | ログイン |
| `npm run inspect` | 画面のつくりを調査 |
| `npm run track -- --all` | 出品中の商品をまとめて登録 |
| `npm run track -- <URL>` | 商品を1つ登録（`--stock=3` で在庫指定） |
| `npm run stock -- <ID> <個数>` | 在庫数を変更（`none` で無制限） |
| `npm run list` | 状況を表示 |
| `npm run once` | 売却チェックを1回だけ |
| `npm run relist -- <ID>` | 手動で再出品 |
| `npm run watch` | 常駐（見張り + 操作画面） |
| `npm test` | 動作テスト |

## 設定ファイル

`config.json` で細かく調整できます。画面から変更できるのは一部だけです。

| 項目 | 内容 |
|---|---|
| `pollIntervalMinutes` | 確認の間隔（分）。10未満は強制的に10になります |
| `jitterMinutes` | 間隔に足すランダムなブレ |
| `maxRelistsPerDay` | 1日の再出品上限 |
| `activeHours` | 動作する時間帯 |
| `minSecondsBetweenActions` | 操作と操作のあいだの最小秒数 |
| `headless` | `true` にするとブラウザを画面に出さずに動かす |
| `uiPort` | 操作画面のポート番号 |
| `browserExecutablePath` | 使うChromiumを指定したい場合だけ |

## セレクタの調整

サイト依存の情報はすべて `selectors.json` の1ファイルに隔離してあります。**コードは触らず、ここだけ直せば追従できます。** 各項目は候補の配列で、上から順に試して最初に見つかったものが使われます。

`npm run inspect`（または画面の手順2）で `data/inspect/` に以下が出ます。

- `*.hints.json` — 入力欄・ボタン・見出しなどの候補セレクタ一覧
- `*.png` — その画面のスクリーンショット
- `*.html` — 生のHTML

## VPSで常時稼働させる（Docker）

パソコンを閉じても動かしたい場合。ログインだけは画面が必要なので、手元で済ませてから `data/auth.json` を持ち込みます。

```bash
# 1. 手元のPCで
npm run login
scp data/auth.json user@your-vps:~/price-tracker-app/bot/data/

# 2. VPSで
cd price-tracker-app/bot
cp config.example.json config.json
# config.json の headless を true にする（画面がないため）
docker compose up -d
docker compose logs -f
```

操作画面はSSHトンネルで見てください。

```bash
ssh -L 8787:localhost:8787 user@your-vps
# → 手元のブラウザで http://localhost:8787
```

> ⚠️ 操作画面には出品を実行するボタンがあります。**インターネットに直接公開しないでください。**
>
> `Dockerfile` のイメージ版と `package.json` の `playwright` の版は**必ず一致**させてください（現在 1.62.1）。ずれるとブラウザを見つけられず起動しません。

## テスト

```bash
npm test
```

Yahoo!フリマを模したモックサイトを立てて検証します。

- `test/e2e.mjs`（29項目）— 登録 → 売却検知 → 承認待ち → お試し → 実出品 → 引き継ぎ → 在庫 → 1日上限 → 緊急停止
- `test/ui-e2e.mjs`（21項目）— 実際にブラウザで操作画面を開き、ボタンを押して動作を確認

**これは自作モックに対するテストなので、「本物のYahoo!フリマで動く」保証ではありません。** 検証しているのはロジックであって、セレクタの正しさではありません。
